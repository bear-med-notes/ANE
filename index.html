第一部分：呼吸道評估、插管與呼吸生理

困難呼吸道評估 (LEMON 法則與特徵)

112-2-1111-1-76109-1-1
  • 困難插管高風險族群：
    • 唐氏症 (小口、大舌頭、下頷突出、頸部伸展受限)
    • 類風濕性關節炎 (頸椎不穩定、顳顎關節功能不良)
    • 阻塞性睡眠呼吸中止症 OSA (肥胖、口咽狹窄、粗短脖子)
    • 下頷後縮等
  • LEMON 評估法：
    • Look externally：下頷短、短頸、肥胖、下巴內縮
    • Evaluate 3-3-2：張口小於 3 指幅、下頷前緣到舌骨小於 3 指幅、舌骨到甲狀軟骨小於 2 指幅
    • Mallampati 分級：請病患張大嘴 (不發聲)，觀察口咽狹窄程度
      • Class I：可見懸壅垂、軟顎、兩側咽弓
      • Class II：可見軟顎、兩側咽弓，但懸壅垂被舌根遮住
      • Class III：僅看到軟顎基部 (Soft palate)
      • Class IV：完全無法看到軟顎 (Hard palate only)
    • Obstruction：呼吸道內外有阻塞
    • Neck mobility：頸椎骨折、僵直性脊椎炎、RA 等活動受限

快速順序插管 (RSI)
[114-2-1]		 ● 適用於「飽食、孕婦、腸阻塞」等高吸入性肺炎風險病患
● 步驟：
→ 預先給氧
→ 給予誘導藥
• Kentamine (1-2mg/kg)
→ 快速肌肉鬆弛劑
• Succinylcholine 或 Rocuronium
→ 施壓環狀軟骨 (Cricoid pressure)
→ 插管

⚠️ 考點提醒：
• 不適合用光纖內視鏡輔助插管 (增加缺氧時間)
軟式光纖支氣管鏡
[113-1-1]		 ● 困難插管、頸部伸展禁忌症 (頸椎骨折) 的首選工具
● 可清醒插管、經鼻或經口插管，對氣道傷害較小
口咽 / 鼻咽人工氣道 ● 口咽氣道 (OPA)：僅適用於昏迷病患
• 清醒者會誘發嘔吐與氣管痙攣
● 鼻咽氣道 (NPA)：清醒或昏迷皆可使用
• 禁忌症為「顱底骨折、凝血異常」
環甲膜切開術 ● 適用於 無法插管且無法通氣 (CVCI) 的極度緊急狀況
● 禁忌症：六歲以下兒童
(因環甲膜過小，應改用針刺氣管造口術或經氣管噴射通氣)

[114-1-1]		 ● 舌咽神經 (glossalpharyngeal nerve) [口咽]
• 阻斷口咽反射
● 上喉神經 (Superior laryngeal nerve) [喉入口以上)]
 • 減少喉反射
● 經喉膜阻斷 (translaryngeal) [聲門下]
 • 麻醉聲膜下黏膜感覺
⚠️ 考點提醒：
 • 不可阻斷喉返神經，否則會導致聲門關閉與呼吸道阻塞

急性併發症與 ARDS 呼吸設定

114-1-9112-2-9108-1-8108-1-1
  • 喉頭痙攣 (Laryngospasm)：
    • 麻醉深度不足時受分泌物刺激引起之聲帶反射性閉鎖
    • 處置為移除刺激物、加深麻醉，嚴重時給予短效肌鬆劑 (Succinylcholine)
    • 嚴重併發症為負壓性肺水腫 (Negative-pressure pulmonary edema)
  • 急性呼吸窘迫症候群 (ARDS)：
    • 柏林定義 (Berlin definition)：一週內發生的呼吸症狀惡化、雙側肺部浸潤、排除心因性肺水腫、PaO2/FiO2 ≤ 300
    • 呼吸器設定 (肺保護策略)：
      • 潮氣容積 (Tidal volume) 降至 6 ml/kg (以預測體重計算)
      • 維持高原壓 (Plateau pressure) < 30 cmH2O
      • 給予適當的 PEEP
      • 可允許「允許性高碳酸血症 (Permissive hypercapnia)」

脈搏血氧飽和度 (SpO2) 與二氧化碳監測 (EtCO2)

114-2-3114-1-3113-2-3113-1-2112-2-3111-1-1110-1-2109-1-2
監測項目 原理與臨床意義 異常變化與誤差原因
SpO2 (血氧)
(Pulse oximeter)
[114-1-3]
[113-1-2]		 ● 主要測量動脈血
● 利用氧合血紅蛋白 (02Hb) 和去氧血紅蛋白 (de02Hb) 對這兩種光波長的吸收率不同
● 利用光波長吸收率計算
• 紅光 660 nm
• 紅外光 940 nm
● 反映組織血氧狀況，與 PaO2 呈非線性關係
● 可利用波形得知是否心律不整
⚠️ 考點提醒：
• 無法監測酸鹼中毒		 ● 假性偏高：一氧化碳中毒 (COHb)
● 假性偏低或測不到：
• 變性血紅素 (MetHb，固定約85%)
• 周邊灌流不良 (休克、低溫)
• 深色指甲油
EtCO2 (潮氣末二氧化碳)
[113-2-3]		 ● 確認氣管內管位置在氣管內的最準確 / 黃金標準
● 正常波形呈高原狀 (Plateau)		 ● 突然歸零：
• 氣管管路脫落
• 誤插食道
● 數值急遽下降：
• 肺栓塞 (血流減少致死腔增加)
• 心搏驟停
● 數值上升：
• 惡性高熱
• 甲狀腺風暴

血行動力學與其他監測 (CVP, PAWP, SVV, BIS)

114-1-7114-1-2113-2-2112-2-2111-2-2111-1-2109-2-3109-2-2108-1-2
  • 肺動脈導管 (Swan-Ganz)：測得的肺動脈楔壓 (PAWP/PCWP) 最接近左心室舒張末期壓力 (LVEDP)，用於評估左心前負荷
  • 動態指標 (SVV / PPV)：
    • 中型以上手術評估血管內容積反應性 (Fluid responsiveness) 優於靜態指標 (CVP)
    • 在正壓呼吸下測量最準
  • 靜脈血氧飽和度 (SvO2)：
    • 正常約 70-75%，測量全身氧氣供需平衡。敗血症、氰化物中毒會使 SvO2 上升 (組織無法利用氧氣)
    • 發燒、疼痛、心輸出量下降會使 SvO2 下降 (氧氣消耗大)
  • 腦波與麻醉深度監測 (BIS / EEG)：
    • 大腦的波形變化符合以下：
      • 大腦越忙碌（清醒、思考）：大腦皮質細胞各忙各的，電波互相抵消 → 高頻率、低振幅
      • 大腦越休息（沉睡、受損）：大腦皮質細胞失去獨立功能，開始同步化集體放電 → 低頻率、高振幅
      • 將腦波按意識由清醒 到 深睡/受損的順序排列，即為：γ→β→α→θ→δ
    • 頻率數字的記法：以「4」為基準跳躍, 最大30 (0-4, 4-8, 8-12, 12-30, >30)

體溫調節與低體溫 (Hypothermia)

112-1-2111-1-3108-2-1
  • 麻醉中最常見的體溫異常為低體溫 (Hypothermia)
  • 體溫下降三階段：
    1. 體溫重新分布 (Redistribution)：
      1. 麻醉後第 1 小時下降最快 (1-2°C)
      1. 因麻醉藥導致血管舒張，核心高溫血液流向周邊冷組織
      1. 預熱 (Pre-warming) 可有效預防
    1. 熱量散失：後續 2-4 小時穩定下降
    1. 平衡期

[112-1-76]		 ● 促進 GABAA 受體
● 降腦壓、降血壓、抑制呼吸		 ● 誘導最常用
● 有止吐效果 (防 PONV)
● 副作用：
• 注射痛
• 掉血壓 (除了Thiopental其他幾個不會)

Ketamine
[112-1-5]		 ● NMDA 受體拮抗劑

• 抑制腎上腺皮質功能 (降低 Cortisol)

● 專一性解毒劑為 Flumazenil

● 降腦壓、升心跳		 ● 適合幼兒的麻醉劑

MAC 核心定義與藥效原理

  • 最低肺泡濃度 (MAC) 之定義
    • 定義：
      • 在對 50% 的患者施加有害刺激時，能抑制其產生主動意向運動所需的最低肺泡（呼氣末）麻醉藥濃度
      • 用以衡量吸入性麻醉藥的效力 (Potency)。
    • 梅耶-歐佛頓假說 (Meyer-Overton hypothesis)：
      • 吸入性麻醉劑的脂溶性越高，穿透細胞膜能力越強，其麻醉效力越強
      • 藥物效力的對數值與脂溶性呈正比例線性關係
  • 影響 MAC 的臨床變數與修正
    • 年齡定量規律：隨著年齡增長，每增加十歲，MAC 值會降低約 6-7%（即高齡患者所需藥量減少）
    • 調降 MAC 因子（患者對藥物敏感度增加，需減少藥量）：
      • 生理與疾病：年紀大、低體溫、嚴重低血壓、孕婦、貧血、甲狀腺功能低下
      • 藥物交互作用：急性酒精中毒、長期使用安非他命者
    • 調升 MAC 因子（患者對藥物耐受度增加，需增加藥量）：
      • 生理與疾病：年紀小（嬰兒）、高體溫（發燒）、甲狀腺功能亢進
      • 藥物交互作用：慢性酒精濫用者、急性安非他命中毒
    • 不影響 MAC 的因子： 麻醉時間長短、性別、身高、體重、高血壓疾病本身
  • 血液/氣體分配係數 (B/G ratio)：
    • 決定麻醉「誘導與恢復的快慢」
    • B/G 越小，代表越不易溶於血，誘導與甦醒越快

臨床生理效應與常見氣體特徵

  • 血流動力學效應
    • 通則：絕大多數吸入性麻醉劑皆會放鬆血管平滑肌，進而引發全身血管舒張與心輸出量調控改變，臨床表現為低血壓
    • 例外：一氧化二氮 (N2​O) 對心血管系統的平滑肌與交神經平衡影響最小，較不易引起低血壓
  • 高頻核心氣體特徵對照
    • Desflurane (水溶性低→穩定)
      • 優點：血液／氣體分配係數（B/G ratio）最小（0.42），體內吸入與排泄最快，臨床誘導與甦醒最快
      • 缺點：具具強烈刺激性，易誘發氣管痙攣與咳嗽，臨床上不適合作為孩童的吸入式麻醉誘導
    • Sevoflurane (水溶性低→穩定)
      • 優點：氣味無刺激性，臨床最常規用於孩童的吸入式麻醉誘導
      • 缺點：與呼吸器內二氧化碳吸收劑（鹼石灰）作用後，易產生具腎毒性之產物 Compound A
    • Nitrous Oxide (N2​O / 笑氣)
      • 特點：MAC 最大（>100%），代表其麻醉效力最弱，無法單獨維持常規全麻
      • 禁忌：
        • 具有高度組織穿透與擴散力，會擴張體內封閉腔室
        • 臨床上腸阻塞、氣胸、氣腦症、中耳手術患者絕對禁用

低流量麻醉 (Low-flow Anesthesia) 臨床實務

  • 定義與臨床定位
    • 定義：在建立穩定麻醉深度後，將呼吸器的新鮮氣體流量（Fresh Gas Flow）調降至每分鐘 0.5-1 L/min 的操作方式
    • 優點：大幅減少麻醉氣體的消耗與浪費、具備高度經濟效益、並能顯著降低手術室對外環境的麻醉廢氣污染
  • 物理限制與麻醉劑選擇選擇（詳解脈絡補足）
    • 迴路風險：因新鮮氣體輸入量少，系統屬於半封閉狀態，必須嚴密監測有毒氣體（如 CO2​）在呼吸迴路內的蓄積
    • 氣體溶解度之關鍵鑑別：
      • 水溶解度高（如 Isoflurane）：氣體易溶解於迴路內的冷凝水或組織水分中，在低流量狀態下，其肺泡與血液間的濃度平衡極難建立，不易穩定維持臨床所需的麻醉濃度
      • 水溶解度低（如 Desflurane、Sevoflurane）：幾乎不溶於水，濃度不會被迴路水分稀釋，在低流量環境下仍能精準且快速地調整並維持穩定的體內麻醉濃度

術後殘留肌肉神經阻斷與逆轉處置要點 [113-1-3]

  • 麻醉策略與殘留風險比較
    • 使用吸入性氣體麻醉相較於靜脈麻醉（TIVA），更容易增加術後殘留肌肉神經阻斷的風險（因氣體麻醉劑本身具有協同放鬆肌肉的作用），此現象在高齡患者尤為顯著
  • 膽鹼酯酶抑制劑 (Neostigmine) 使用時機
    • 藥理機轉：藉由抑制乙醯膽鹼酯酶，增加神經肌肉交界處的 Acetylcholine 濃度，以競爭對抗非去極化肌肉鬆弛劑
    • 臨床重點：
      • 必須在病人已有自發性呼吸跡象或肌肉功能開始有一定程度恢復時方可給藥
      • 若在完全沒有自發恢復的情況下過早給予，易導致藥物持續蓄積或引發再阻滯 (Recurarization)，導致術後嚴重肌肉無力
  • Sugammadex 緊急逆轉應用限制
    • 臨床應用：常用於氣管插管通氣失敗時的緊急逆轉 (Emergency reversal)。
    ⚠️
    考點提醒：
    • 僅能逆轉 Rocuronium 與 Vecuronium
    • 若臨床插管使用的是 Cisatracurium 或去極化型的 Succinylcholine，Sugammadex 完全無效
  • 四聯刺激 (Train-of-Four, TOF)：評估肌鬆劑恢復程度
    • TOF Ratio = 第四下收縮振幅 / 第一下收縮振幅 (測量內收拇指肌)
    • 拔管標準：TOF ratio ≥ 0.9，確保呼吸道反射與肌肉力量恢復，減少術後殘餘無力風險
    • 臨床效益：此數值為臨床安全拔管的客觀指標，可顯著降低術後缺氧、呼吸道阻塞及延長住院的風險

局部麻醉藥 (Local Anesthetics) 與 LAST

112-2-4111-1-4110-2-5110-1-7110-1-4108-2-3
  • 機轉：阻斷神經細胞膜上的電位門控鈉離子通道 (Voltage-gated Na+ channels)
  • 局部麻醉藥物分類：
    • 醯胺類 (Amides)：
      • 字尾含兩個 "i" (如 Lidocaine, Bupivacaine)
      • 由肝臟代謝，較不易過敏
    • 酯類 (Esters)：
      • 字尾只有一個 "i" (如 Procaine)
      • 由血液中偽膽鹼酯酶代謝，代謝快但較易引發過敏 (因代謝物 PABA)
  • 添加 Epinephrine 的好處：使局部血管收縮，減少藥物吸收入血，延長麻醉作用時間，並減少全身毒性
  • 局部麻醉藥全身性毒性 (LAST)：
    • 症狀進展：先出現中樞神經 (CNS) 毒性 (嘴唇發麻、耳鳴、金屬味、痙攣/Seizure) → 晚期出現心血管 (CVS) 毒性 (心律不整、心室頻脈、心搏暫停)
    • 急救特效藥：Intralipid (Lipid emulsion，脂質乳劑)，作為「脂質沈船效應」吸附藥物

疼痛管理與鴉片類藥物 (Opioids)

114-1-8113-2-8112-2-8112-2-5112-1-4109-2-8109-1-5108-1-7108-1-6
  • 疼痛名詞定義：[113-2-8]
    • Allodynia (痛覺超敏)：對原本不該感到痛的刺激 (如輕觸) 感到疼痛
    • Hyperalgesia (痛覺過敏)：對疼痛刺激的反應不正常地上升
    • 理解：
      • -dynia → 對不應該感到痛的刺激感到痛
      • -algesia → 對會感到痛的刺激感到程度差異 (An-, Hyper-, Hypo-)
      • -esthesia → 對所有刺激感到程度差異
  • 鴉片類藥物機轉：
    • 結合 Mu, Kappa, Delta 受體 (G-protein coupled) → 抑制腺苷酸環化酶 → 促進鉀離子外流 (細胞過極化) / 抑制鈣離子內流
  • 副作用：
    • 呼吸抑制、噁心嘔吐、便秘、縮瞳
    • 大劑量快速給予 Fentanyl 等強效藥物會引發胸壁僵硬 (Chest wall rigidity)，影響通氣
  • 解毒劑：Naloxone (純 Mu 受體拮抗劑)
  • 病患自控式止痛 (PCA)：
    • 主要使用 Opioids (如 Morphine, Fentanyl)
    • 病患需意識清楚能配合按鈕
  • 癌症疼痛：
    • 長效控制常使用口服或皮下/經皮吸收 (如 Fentanyl patch)
    • Meperidine 因其代謝物會累積引發神經毒性與癲癇，不建議用於慢性或癌症疼痛的長期控制

特殊疾病麻醉注意事項

114-2-7114-2-6109-1-3108-2-7108-2-6108-1-5

孕婦麻醉

  • 生理變化：
    • 心輸出量 (CO) 增加
    • 功能性肺餘容量 (FRC) 降低 (易缺氧)
    • MAC 下降
    • 下食道括約肌張力下降 (易逆流)
  • 平躺會造成仰臥低血壓症候群 (壓迫下腔靜脈 IVC) → 處置為子宮左推 (或右臀墊高)
  • 剖腹產全麻：
    • 一律視為飽食 (Full stomach) → 採用 RSI 快速順序插管，預防吸入性肺炎
    • 肌鬆劑選擇：
      • 快速順序插管 (RSI) 首選 Succinylcholine (SCH)
      • 因其起效快、代謝迅速，且極少通過胎盤，不影響新生兒自主呼吸
    • 鴉片類藥物時機：
      • Opioids（及苯二氮平類 BZD）必須在胎兒娩出後才可由靜脈給予，以避免娩出前經胎盤導致新生兒呼吸抑制
    • 麻醉維持調控：
      • 胎兒娩出後，吸入性麻醉氣體濃度應調降至 0.5 MAC，並改以靜脈藥物維持
      • 主因為高濃度吸入性麻醉劑會抑制子宮平滑肌收縮，增加產後大出血風險

老年人麻醉

  • 器官功能與儲備力 (Functional reserve) 下降，藥物需求劑量減少
  • 術後常見併發症為術後譫妄 (POD) 與術後認知功能障礙 (POCD)

肥胖病患 (BMI > 30)

  • 極易合併阻塞性睡眠呼吸中止 (OSA)，為困難插管的高風險群
  • 功能性肺餘容量 (FRC) 顯著下降

嚴重主動脈瓣狹窄 (Severe AS)

  • 麻醉原則為維持足夠的前負荷 (Preload) 與後負荷 (Afterload)，避免心跳過快或過慢 (維持 Sinus rhythm)
  • 切忌因血管過度擴張導致嚴重低血壓

心律調節器 (CIED) 病患

  • 術前應評估是否需改為非同步模式 (Asynchronous mode)
  • 術中應避免電燒刀干擾，心電圖監視器應調整至 Monitor / Filter mode (以免干擾波影響判讀)，並搭配動脈導管或 SpO2 確認實際血流脈搏
